# Tutorials

Step-by-step guides for common SafeVixAI tasks.

## Available Tutorials

- [Set up SOS Alerting in 5 Minutes](sos-setup.md) — Configure emergency SOS alerts, test the hold-to-activate flow, and verify SMS/WhatsApp notifications
- [Integrate the Challan Calculator](challan-integration.md) — Add fine calculation to your app using the SafeVixAI API and DuckDB-Wasm offline support
- [Customize the AI Chatbot](chatbot-customization.md) — Configure LLM providers, add custom tools, and tune the chatbot for your use case

## Prerequisites

Before starting any tutorial, ensure you have:

1. A running SafeVixAI instance (see [Setup Guide](../../SETUP.md))
2. API access credentials (JWT token for authenticated endpoints)
3. Basic familiarity with REST APIs and HTTP clients

## Tutorial Format

Each tutorial includes:
- **Time required** — estimated duration
- **Prerequisites** — what you need before starting
- **Step-by-step instructions** — numbered steps with code snippets
- **Verification** — how to confirm the tutorial worked
- **Troubleshooting** — common issues and solutions
