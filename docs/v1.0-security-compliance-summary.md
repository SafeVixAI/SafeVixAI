## 1. Authentication & Authorization

| Control | Status | Implementation |
|---------|--------|----------------|
| JWT authentication | ✅ | RS256 + HS256 dual support |
| JWKS key rotation | ✅ | Atomic fetching with stampede protection |

| RBAC roles | ✅ | Operator, Officer, Administrator, Super Administrator |

| CORS with production guard | ✅ | Fail-fast if wildcard `*` in production |
| CSRF protection | ✅ | Token-based, per-session |
