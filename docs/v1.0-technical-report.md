## 6. Enterprise Patterns

| Pattern | Implementation | Used By |
|---------|---------------|---------|
| CQRS | Command/Query buses with middleware | Roadwatch reports |
| Redlock distributed locking | Redis SET NX EX + local fallback | Idempotency, cache stampede |
| JWKS key rotation | Automatic key refresh with stampede protection | JWT validation |
| Circuit breaker | 3-failure threshold, 30s half-open | All 8 external API calls |
| Cache stampede protection | SET NX EX mutex + stale-while-revalidate | Redis caching |
| Rate limiting | Token bucket per endpoint | All API routes |
| Idempotency keys | SHA-256 hash + distributed lock | Critical POST endpoints |
| 10-provider LLM fallback | Sequential with timeout | Chatbot responses |
| Email alerting | SMTP with 5-min cooldown | All-provider failure, DB errors |
